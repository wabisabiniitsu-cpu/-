# ハリナビ コラム記事 画像生成ルール（ChatGPT用）

記事担当が画像のaltテキスト・生成内容を提案する際、このルールに沿った指示文を作ること。
実際の画像生成はChatGPT（外部ツール）で行うため、記事担当はここに書く形式の「生成指示文」を作るところまでを担当する。実際の生成・サイトへのアップロードは社長が行う。

---

## 共通条件

- サイトURL：https://www.harinavi.jp/
- ブランドカラー：ホワイト×ベージュを基調とした空間。アクセントカラーはマゼンタピンク（#c70070）を、小物・花・タオルの刺繍などに「さりげなく1点だけ」配置
- ライティング：窓からの明るい自然光（ハイキー）。透明感・清潔感のあるプロフェッショナルな商業写真スタイル。背景は美しくぼかす
- サイズ：横長 1200px × 630px

## 人物の描写ルール

- 登場人物（施術者・クライアント）は全員30代〜40代の日本人女性（実写）
- 人物は毎回別人でよい。手元だけの描写でも女性と分かるようにする
- プロの一眼レフで撮影したような、加工感のないリアルな質感（肌のテクスチャ・光の反射を自然に）

## 日本語表示の厳格ルール（最重要）

- 看板・ノートの書き込み・本の表紙・ラベル等に文字を入れる場合は、必ず意味の通じる正しい日本語（漢字・ひらがな・カタカナ）のみにする
- 英語・アルファベット・意味不明な記号・鏡文字・崩れた文字は1文字たりとも含めない
- AIが正確な日本語を描写できない場合は、文字を一切入れず無地のクリーンな状態にする

## TOP画像（記事ごとに1枚）

指示文の型：
```
添付画像は自社開発の美容鍼・不妊鍼灸の専門ポータルサイト内の一部のコラム記事で使用しているTOP画像です。
その画像と下記の情報、条件を厳守してコラム記事のTOP画像を作成してください。

##TOP情報
・サイトURL：https://www.harinavi.jp/
・タイトル：〇〇〇〇（記事タイトルをそのまま入れる）

##条件
・添付画像を参考にして文字の色合い、背景のベースはそのままでいいから、右側のデザインは前回作成したものとは違うデザインにして
```

【日本語表示と実写リアリティの厳格な指定】
